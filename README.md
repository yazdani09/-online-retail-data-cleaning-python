# Week 1 Data Cleaning Project

## Project Overview

This project focuses on reviewing, cleaning, and preparing an online retail dataset for further data analysis.

The main objective is to understand the dataset, identify data quality issues, clean the data, and prepare a reliable dataset for analysis and visualization.

## Objectives

- Review the structure and quality of the dataset
- Identify missing and inconsistent values
- Handle duplicate and invalid records
- Clean and prepare the dataset
- Perform basic data review and analysis
- Generate useful visualizations and insights

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis & Visualizations

The project includes analysis and visualizations covering:

- Hourly sales
- Monthly sales
- Yearly sales
- Top countries by sales
- Top products
- Customer transactions
- Transaction amounts

## Project Outcome

The dataset was cleaned and prepared for further data analysis and visualization. The project also documents the data-cleaning process and presents the results through relevant visualizations.
